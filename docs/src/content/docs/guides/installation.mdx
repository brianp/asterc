## Install

### macOS

```bash
curl -fsSL https://aster.dev/install.sh | sh
```

### Linux

```bash
curl -fsSL https://aster.dev/install.sh | sh
```

### Windows

```powershell
irm https://aster.dev/install.ps1 | iex
```

### Verify

```bash
aster --version
```

## Running Aster Programs

```bash
# Run an Aster source file
aster hello.aster

# Type-check without running
aster check hello.aster
```
