**Status:** Draft

Proposes first-class runtime introspection of classes and error hierarchies — ancestors, traits, fields, and methods. Inspired by Ruby's reflection model, with future direction toward metaprogramming and decorators.

## Key Ideas

- **Runtime class introspection**: query ancestors, included traits, fields, and methods.
- **Error hierarchy traversal**: walk up the `extends` chain at runtime.
- **Ruby-inspired model**: familiar API for developers coming from dynamic languages.
- **Future direction**: metaprogramming and decorator support.
